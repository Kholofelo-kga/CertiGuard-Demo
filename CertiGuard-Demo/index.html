About CertiGuard Demo

What this prototype demonstrates

  • Certificate upload and browser-side file fingerprinting
  • OCR review/correction workflow
  • Institution record cross-validation
  • Computer-vision tamper-check interface
  • Fraud risk classification workflow
  • XAI evidence presentation
  • Administrator audit trail and report generation

Evidence boundary

Real/live in this prototype: selected file metadata, SHA-256 hash, image preview, form validation, reference-record matching, audit events and report generation.

Demonstrated rather than experimentally measured: OCR extraction accuracy, CV tamper probability, ML fraud score and XAI heatmap. These require the FastAPI/AI backend described in the architecture.
