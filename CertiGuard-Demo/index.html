About this Demonstration

CertiGuard

This static web application demonstrates the proposed CertiGuard interface and end-to-end workflow for academic certificate verification.

Architecture represented

Presentation layer → FastAPI-style application services → AI Verification subsystem (OCR, computer vision, fraud scoring and XAI) → data layer and external institution records.

Important academic note

This Vercel demo does not claim real model performance. OCR confidence, tamper confidence, risk scores and classifications are generated locally in JavaScript to demonstrate system behaviour. They must not be reported as experimental results.
